## 状态不是百分比

`State`记录一项交付物已经通过的最高验收门，而不是完成百分比；它只能随新的、可复验的证据前进，不能跳级。旧版本以`Superseded by`退出当前门，不以状态回退伪造历史。设计和视觉资产的终态可以是`MERGED`；视觉`FROZEN`不等于`IMPLEMENTED`，静态SQL验证也不等于`RUNTIME_VERIFIED`。

`MERGED`证据单元格只允许一个或多个以`; `分隔的仓库内Markdown证据链接，并以最终代码形式`` `merge-commit=<sha>` ``结束；该提交必须在本快照可达且包含该行全部Artifact。链接或标记前后及两者之间不允许任意说明文字。

## R2 entry gate matrix

- PR2 closure documents and the frozen visual bundle must first reach `MERGED`.
- After PR2 merges, the runtime plan must create or advance the separate `DB-52P2-PG18-RUNTIME` row to `RUNTIME_VERIFIED`; that row is intentionally absent now, while `DB-52P2-CONTRACT` and `DB-52P2-MIGRATIONS` remain `MERGED`.
- The separately locatable `R1-OPENAPI`, `R1-BACKEND`, and `R1-SPA` rows must reach `IMPLEMENTED`; `R1-E2E-GOLDEN` and `R1-E2E-FAILURES` must reach `RUNTIME_VERIFIED`.
- Those five R1 rows are intentionally absent until source and evidence exist. `R1-IMPLEMENTATION-PLAN` is an allowed `DRAFT` plan, but a plan is not production code and cannot satisfy this gate.
