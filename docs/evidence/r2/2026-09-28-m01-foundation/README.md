## 本轮实现

- PaymentLedgerReader：具名财务元数据候选读取，同租户关联当前工作流；按不可变收款请求ID做1–100条有界键集分页，限定阶段筛选。收款完成后保留记录，后续凭证对应独立请求，旧工作流不重复列出。
- TransferLedgerReader：具名转案元数据候选读取，按不可变转案请求分页，仅取当前责任；不预先读取案件身份、材料或合同正文。
- 两个端口都是内部候选读取，不是授权后的响应，未对HTTP开放；业务层仍须逐项授权、保护准确事实并审计。未修改现有PaymentWorkflowPorts权限映射，未授予账号权限。
- ManagementLedger：复用BusinessNavigation与ledgerMaster.css，按R稿展示收款/转案视图。服务端驱动查询；不在组件推算金额或授权。失权、加载或失败不保留旧明细，详情ID必须匹配选中行，只读不显示办理按钮。仅输出准确请求ID供后续受控办理接线；当前未挂载到运行路由。
