# U 个人等待事项实现与验证

日期：2026-09-29。依据：已确认的 U 补稿及“完整实现该功能”授权。

## 实现范围

- 当前工作卡下默认收起的本人等待列表，报价工作卡同样提供入口；列表就地展开只读详情，不更换路由或当前工作卡。
- 与当前卡等待数共用本人/授权代办的可见集合。分页每页最多 20 项；稳定游标在集合变化时失效并要求重读。数量为完整授权集合，不是当前页行数。
- 区分未到约定时间、等待条件满足、已到核对时间。经过时间不等于已可办理，也不把到期等待自动标为责任异常。
- 展示实际等待事实的原因、时间、负责人、下一步和最近记录。展开时及可见窗口聚焦/每 30 秒重读；读取失败、失权、身份变化清除旧详情，无法核对时数量显示未知。
- 服务端核对原卡任务、对象版本、草稿状态和授权后才能返回 READY。跳转先执行当前卡草稿保护，再读精确目标；核对期间输入和导航锁定，切换时清除旧合同/分类纠正覆盖卡。
- 复用敏感读取事务、授权和披露审计，审计失败不返回业务内容。两个新接口仅 GET，禁止客户端指定其他任职范围，无业务写入、提前唤醒或团队权限扩展。数据库契约保持 v20。
