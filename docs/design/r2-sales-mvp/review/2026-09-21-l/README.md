审阅重点：准备来源是否明确；付款与签署要求是否易懂；左右工作卡是否保持冻结母版；退回、失权、未知结果和后继是否给出准确下一步。顶部场景选择器只用于查看不同角色，不是用户可越权跳转的产品导航。

所有数据只在当前页面内存中。保存草稿、审批与正文均为模拟，不访问数据库/API、不调用电子签、不产生可签署文件。审批角色完成后显示本人的办理结果，不自动切换为销售。台账选择后显示详情，筛选清除旧详情。原提交结果未知时禁止切换业务入口。

批准仅覆盖本包画面及交互，不授予 R1/R2 业务发布验收，不把签署、到账、转案或案件分类视为已实现。原用户“缺失高保真先确认”的约束继续适用。
