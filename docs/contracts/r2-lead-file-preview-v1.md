# R2 线索文件读取与预览 V1

所属工作包：R2-1。实施依据为已确认的完整 R2 计划和 HF-03 字段映射/预览方向。本次只实现读取与校验，不修改页面视觉、导航、权限或销售业务状态。

## 读取与映射

- `readLeadImportFile` 支持 UTF-8 CSV（含 BOM）及单工作表 XLSX；先检查文件元数据，再检查实际读取的字节数，最多 1 MB。文件/身份切换时调用方通过 AbortSignal 取消，已取消结果不能继续用于预览。
- 文件仅在内存中读取一次，对外提供只读表头及映射预览方法。文件选择不调用录入接口、不写浏览器存储、不创建线索或待办。
- 两种格式复用同一 `previewLeadTable` 业务字段检查，保留原来源记录键、姓名/需求长度、E.164 电话、邮箱、SafeText 控制字符与所有重复行错误。校验不替代服务端授权和规则。
- XLSX 依据工作簿中的关系定位唯一工作表；读取共享字符串、内联文本和富文本，排除注音附注。保留实际行号，不因空行而重新编号。按 [Microsoft ST_Xstring 说明](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oe376/bd0aa042-434a-4ca7-b25f-4e1fd25a954d) 单次解码 Excel 转义，保留转义后的字面编号，控制字符继续进入共享字段校验。
- 数字类型来源记录号标为错误，要求核对并改为文本，避免前导零或精度已变化却被静默录入。不能从数字格式推测原编号。

## 有界兼容范围

首版面向单表线索模板，不是通用电子表格工具：最多 200 条非空数据行、64 列，第一行为唯一非空表头。拒绝多工作表、隐藏内容、合并单元格、公式（含缓存结果）、宏和嵌入对象。用户修正原文件再核对；不自动选表、拆分合并单元格或计算公式。

支持普通 UTF-8 OOXML XLSX（2006 命名空间、Store/Deflate ZIP）。不支持 XLS、XLSM、加密文件、分卷/ZIP64、外部工作表或扩展工作表路径；不访问工作簿链接、不执行外部内容。只解析所需工作簿 XML，未将样式/图表/透视功能纳入 R2。

ZIP 目录必须完整，中央目录与本地文件名/压缩方式/大小一致，目录条目不重复、不越界或重叠。实际解压采用固定小输入块，单 XML 最多 2 MB，所需 XML 总计最多 8 MB，最多 128 个 ZIP 条目；验证实际长度与 CRC，不信任伪造的原始大小。XML 禁用实体/DOCTYPE，拒绝解析错误。
