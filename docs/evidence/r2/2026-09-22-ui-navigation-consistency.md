# R2 工作台与台账一致性修正

范围：按用户明确提出的四项问题修复，沿用冻结 E/L 母版，不扩展业务功能。

## 共性原因与修正

- 首页待办 summary 使用绝对定位，刷新按钮另有移动端 38px 覆盖，导致相邻控件拥挤且不等高。改为正常 flex 布局与 12px 间距，刷新和待办使用同一 workbench-control 尺寸规则。
- 新建 MyTasksControl，工作台队列、报价卡、合同卡及台账侧栏复用同一图标和文字样式；保留原生 details 键盘行为。
- 新建 BusinessNavigation，两种台账共用商机台账、合同台账、我的待办三项入口，当前台账使用 aria-current。取消合同台账左上角返回按钮。
- 合同台账前往办理使用服务端返回的当前合同任务 ID，进入 App 的 work.selectTask，再由当前责任接口核对权限。合同卡嵌入工作台主框架，保留商机台账入口、刷新、我的待办，不再另开办理框架。
- 合同卡向父框架报告 dirty/locked 状态，提供草稿保存句柄，防止切换丢失输入或未知提交期间离开。原有 R1 未知结果恢复和刷新行为保持不变。
- 横向检查发现合同详情两个操作和合同表单提交/保存草稿同样缺少间距，统一使用操作组间距。
