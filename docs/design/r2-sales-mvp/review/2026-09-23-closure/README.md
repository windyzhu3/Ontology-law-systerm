建议核对：
1. 商机卡保留“记录本次进展”主操作；次要“推进或结束本次商机”进入专属办理卡。打开入口不结束跟进，报价准备意图提交成功后才接管。
2. 客户资料未确认时指向缺项；资料维护后返回原业务，再确认开始报价或申请直接合同。无虚填下次跟进时间。
3. 无回复记录联系尝试和下次安排，不算有效进展或客户拒绝；原期限仍可查。
4. 报价结束、未签合同结束、有签署事实申请主管核对为不同目的卡。存在待核验材料也由主管处理；停止办理不解释为解除合同。
5. 主管核对可退回继续或确认停止；已有执行／财务／转案事实和责任保留。
6. 来源请求确认后由主管选择继续分配、约时复查或明确结束本线索；不操作来源全局开关。
7. 等待、原结果未知、提交失败、只读、撤权、无负责人状态，以及 1440／390／360 布局。

产品 UI 在用户确认本包后实施。F02/F03 的既有行为根因修复不依赖此视觉确认。
