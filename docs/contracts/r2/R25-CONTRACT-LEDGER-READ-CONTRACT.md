# R25_CONTRACT_LEDGER_V1

2026-09-28：已确认 R2.5 计划 R25-01 的具名查询后继，不改变写命令、授权/审计语义、旧迁移或业务主链。

- GET `/api/v1/contracts` 保留 HUMAN 自己任职，拒绝代办；无缓存。
- `limit` 默认20、范围1–100；`search` 最多200字符，去首尾空白后大小写无关地匹配客户标签；`state` 最多80字符，精确匹配已展示的当前事项标签；控制字符拒绝。
- 数据库按租户、商机UUID升序独占 after 扫描，单请求最多100个合同候选；无权候选继续扫描，页满或预算耗尽时停止。数据库只返回候选标识，授权后才解密客户和读取列表投影。
- `nextCursor` 是 AES-GCM 不透明位置，最长512，绑定用途、租户、主体、任职、归一化筛选及页长，有效600秒；篡改、跨身份/查询或过期返回 VALIDATION_FAILED。无总数；空页可以带继续游标，客户端提供下一页。
- 返回最多limit行，合同/财务/转案责任展示沿用现有语义；详情按选中记录读取。列表不加载合同正文、草稿正文或完整历史。授权及审计在同一有界事务内完成，失败回滚；未引入跨请求授权缓存。
- 搜索/状态变化清空旧选择并返回第一页。保留现有母版、详情和办理入口，不增加页面。
- 准确传输形状由 `r25_contract_ledger_transport.py` 验证并投影回原T08；原T08摘要保持。

本后继只记录实现合同；规定规模性能、跨任职/租户分页和后台稳定性需各自证据，不自动通过 R25-01 或发布门禁。
