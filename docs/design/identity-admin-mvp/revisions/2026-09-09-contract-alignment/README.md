## 必须保留的交互语义

- 分页依据服务端 cursor；“本页 N 项”仅表示当前页，不表示全目录总量。下一页仅在 nextCursor 存在时启用；上一页仅在本次访问有已保存的前页游标时启用，不提供跳页或总页数。静态图仅示范一种分页状态。
- 组织树连接只依据已加载且获权的节点及准确 parentOrganizationId；未加载父项不能被误称为根，未加载子项不能被误称为无子项。展开只展示已加载关系，不暗示新增子树接口。图中“本页7项”是示例页计数。
- 岗位显示：INTAKE_OPERATOR=线索接入经办；ROUTING_SUPERVISOR=路由主管；CONTACT_OPERATOR=首联经办；IDENTITY_ADMIN=身份管理员（仅既有记录披露，不能在线创建此岗位）。
- 授权示例：SALES_CONTACT_OWNER=首联处置；LEAD_ROUTING_DECIDE=路由处置；LEAD_CAPTURE=线索接入；IDENTITY_PRINCIPAL_MANAGE=身份主体管理（仅既有记录披露，不能在线新增管理授权）。具体提交仍只能选服务端提供的准确任职与准许代码。
- Principal 与 Appointment 的暂停／恢复／禁用／结束按实际状态、权限和服务端前置条件呈现；操作需确认、原因与现有幂等／恢复机制，不新增生命周期规则。用户页选中 ACTIVE；暂停主体的详情需呈现恢复，DISABLED 不提供恢复。任职 ENDED 不提供恢复。
- 建立身份的受控 IdP **完整用户名精确查询**仍保留在新增流程；本次删除的是列表的无合同搜索，不是删除已批准的开户能力。
