# 公共身份、底部按钮与业务管理入口横查

日期：2026-09-29。范围：既有页面 UI 一致性。

## 原因与修正

- SessionApplication 的九处页面分支分别拼接姓名、任职和“管理模式”，部分分支仅显示姓名。统一使用 SessionActions，格式为“姓名 · 当前任职”，保留代办任职提示；切换任职和退出沿用原有离开语义。
- 工作卡、台账、身份管理与弹窗重复定义按钮样式，台账样式动态插入后会影响其他页面。sharedControls.css 按语义统一主按钮（48px / 16px）、次按钮与文字按钮（44px / 15px），保持业务布局的宽度，避免 flex 容器拉伸高度；危险操作保留其危险色。
- 工作台顶部多个管理入口合并为“业务管理”。优先进入有权线索页，否则依次使用有权商机、合同、团队或概览入口；公共侧栏继续负责模块切换。保留原有未保存内容确认与处理中禁用。

## 验证

- Vitest：106 个文件、1072 项测试通过，包括统一入口、跨页身份显示、未保存内容保护、任职切换和退出回归。
- TypeScript 类型检查和生产构建通过；构建仍有既有的大包提示。
- Playwright CLI：生产组件配合合成 transport，在 1280px / 390px 下检查客户与线索、经营概览、团队待办、来源与责任，身份一致、七项公共菜单及图标完整，无横向溢出。
- 浏览器样式样例覆盖 action-area、card-action-area、ledger-detail-actions、identity-form-actions、dialog-actions；在公共样式之后再次加载台账、身份、团队样式，同类按钮的计算高度、字号、背景、文字色及圆角一致。该检查是组件和 CSS 回归，不替代真实角色业务验收。

未扩展业务能力、授权或后端流程；未将本次 UI 检查算作正式试点验收。
