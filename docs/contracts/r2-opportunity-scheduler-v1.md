# R2 商机调度核心 V1

本批承接已确认的内部传输接口，不增加页面、权限、数据库表或业务范围。R2OpportunityTaskScheduler 独立装配，未注册进 R1WorkerDeployment 或生产健康状态。

每个租户绑定及 INITIAL / DUE 各有互斥状态。每次最多读取一页、派发十条命令；五秒单调时间预算在请求之间检查，单次网络请求仍受客户端十秒超时约束。页内位置与最多五十条候选保存在进程内。空页仍按 nextCursor 推进。

200 必须先经过客户端的准确回执校验，统计的是已确认回执（包括 NO_CHANGE），不是新建任务数量。408、429、5xx、传输异常保留原候选和命令键，按 1 / 5 / 30 / 120 / 600 / 1800 / 7200 秒退避。未确认命令优先于下一次业务发现，避免提交成功但响应丢失后无法重放。

400 / 404 / 409 / 412 / 422 记录本次拒绝并继续后续候选；整轮有拒绝则显示 DEGRADED 并在结束后等待六十秒。分页凭据过期只在没有未确认命令时从头发现。401 / 403 按类型隔离：发现被拒则退避；命令被拒且此前结果不明时保留原输入，在发现权限恢复后同键重试；此前没有不明结果则推进该条，重新探测权限后继续原页的后续候选。

快照只包含状态、待处理数、累计确认数、拒绝数及最近 HTTP 状态，不披露客户文本、证书或分页凭据。READY 仅表示本轮可见候选处理结束；发现服务会过滤无效负责人，不能据空页宣称所有业务义务完成。

start 显式启用每秒循环；同一状态不重入，关闭后不再启动下一条请求，不关闭共享客户端。关闭时已发出的请求仍可能提交。进程退出会丢失本地分页、诊断与未确认命令，不提供跨重启检查点或持久异常台账。完成这两项及负责人异常处理之前，不启用生产自动注册，不声明 MVP 验收完成。
