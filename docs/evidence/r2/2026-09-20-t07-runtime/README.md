## 真实运行补充修复

本机 C24 审批决定暴露出命令保存点与 PostgreSQL 子事务 xmin 的差异：领域直接调用通过，但完整命令事务被事件校验拒绝。追加 V960 / v10，为审批决定、交付、回复各自保存不可变事务标记；不改已部署 V950，不以时间接近或事后推断代替写入证据。完整命令的成功、原键重放、历史事实非新写入和 V950 数据迁移回填均纳入回归。

工作卡读取发现报价授权未加入准确披露构造校验，已仅增加四种办理权限的具名来源并验证错槽、委托和错误事实拒绝。台账当前责任使用报价待办的准确任务、负责人、时间与阶段；没有 QUOTE_READ 的用户不披露报价元数据，报价接受后不残留旧任务或假合同任务。

390px 报价核对页未产生横向溢出。折扣勾选框修正为局部 16px 控件，沿用既有绿色；冻结母版 CSS 不变。

最后一轮修正了测试环境仍声明 v9 而实际迁移已到 v10 的不一致；HTTP 验证按准确 v10 重新运行通过，没有放宽运行版本闸门。正常调度版本测试增加 v9/v10 允许、v11 拒绝。

后台读取保留缓存期间允许主动切换待办；选中另一项后中止旧读取并校验响应代次。焦点事件不重复启动在途读取，隐藏页面中止读取后清理加载状态并保留重新核对要求。提交中、未知结果恢复和未保存内容的保护仍保留。新增回归先失败再通过，完整前端742项及类型检查通过。
