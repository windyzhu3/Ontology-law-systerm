# R2-QUOTE-PACKAGE-V1

状态：T07 实施规则；依据已确认 R2 业务范围及 K2 页面。不得解释为生产功能已验收。

## 相对旧基线的具名修订

1. 统一销售入口不要求先选择综法或执行业务。旧执行类折扣分档不能用于此入口。所有报价默认进入审批；只有服务端验证当前任职具备本版范围的明确授权时才可走权限内路径。没有审批矩阵或无合格审批人时进入责任异常，不默认批准、不生成新的金额阈值。
2. QuoteIssued 增加 MANUAL_CONFIRMED 来源，要求准确报价版本、实际接收人、交付时间、交付方式和 T06 准确证据版本；不得伪造供应商发送或回调。下载、材料上传或扫描通过均不产生交付事实。
3. 客户回复沿用 ACCEPTED / NOT_ACCEPTED / REJECTED / AMBIGUOUS。接受必须绑定准确交付、有效报价及证据；暂不接受和不明确均有未来跟进责任；拒绝产生销售处置责任而非自动失单。
4. 合同准备来源保留 ACCEPTED_QUOTE 与后续 DIRECT_AUTHORIZATION 两个互斥来源。本任务只形成前者的准确来源，不创建假报价接受，也不将其视为签署或案件成立。

## 准确报价包

绑定租户、商机、已确认客户需求版本、报价版本号及直接前版；内容含币种、服务范围、显式折扣计价行、固定总额、付款安排、有效截止时间，以及独立的条件性费用依据、基点费率和上限。金额用最小货币单位整数，禁止浮点和隐式精度截断。内容摘要包含以上全部依据，修改任何依据均不得沿用原批准。

R2 首批界面使用 CNY；后端禁止将其他币种默认为两位小数。允许合法零报价，不允许负总额；负计价行必须显式标记折扣。条件性金额不计入已确定固定总额。
