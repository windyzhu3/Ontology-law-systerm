## 实际交互检查

| 路径 | 检查结果 |
|---|---|
| AI 摘要 → 采用 | 生成建议时原字段不变；人工采用后成为待核对内容，不自动提交 |
| 脏表单 → 我的待办 | 出现继续编辑、放弃修改、保存草稿再切换；保存后进入所选合同；同一时刻只显示一张完整工作卡 |
| 合同预览 → 人工勾选 → 提交 | 未预览不能确认；修改内容后须再次核对；结果未知时禁止切换与重复提交，仅保留核对入口；核对后显示审批人及付款约定 |
| 导入 → R1 首联 → 商机 | 远辰公司在三步中身份一致；首次有效联系后显示继续商机跟进，不要求用户跨栏目查找 |
| 管理查询 | 搜索无结果时清空旧详情；清空搜索后恢复记录；状态筛选只显示匹配的华启记录并同步详情 |
| 异常交接 | 缺少接手人与说明时提示补齐；陈晨交接确认后待处置计数4→3；切换记录再返回仍保留接手人 |
| 无候选协调 | 记录后状态为协调中，待处置仍为4；重新选中记录可查看协调说明和下次核对，不宣称异常解除 |
| 小屏详情返回 | 点选记录显示对应详情和处置按钮；返回列表后搜索框获得焦点，查询上下文保留 |
| 只读 | 能查看团队事项，不提供交接主操作 |

## 本轮检查后已修正

1. 程序聚焦 main 出现整块黑色描边：只移除程序容器焦点描边，保留按钮、链接、输入及 summary 的可见键盘焦点。程序焦点不再强制移动滚动位置。

3. 交接和协调结果切换记录后丢失：按记录保留处置结果；不把协调登记变成已解决。
4. 导入客户与固定商机示例文字混用：后继工作卡和待办名称沿用当前客户，避免更新另一客户的管理记录；合同审批后的“下一行动”显示等待审批。
5. 小屏管理列表与详情距离较远：补充点选定位详情及返回列表，保持同页操作。
