# T08 首批实现：合同准备输入

状态：DOMAIN_INPUT_SELF_VERIFIED，T08 整体仍为 IMPLEMENTING。用户已确认 L 高保真及业务设计。

## 本批实现

- ContractPreparationSource：准确报价接受与直接授权为互斥类型；租户、商机、客户确认、商业内容必须匹配。过去合法接受不因当前报价到期失效；直接授权每次以当前时间核对有效区间。
- ContractVersionInput：商业条款、精确金额/折扣/条件收费、付款门禁、正文证据及字节摘要、模板和条款版本、签署要求与参与方快照、版本前序均进入不可变准备输入及摘要。
- 金额限定 CNY 最小货币单位和安全整数边界；不能用负数普通收费隐藏折扣，也不能用条件收费冒充固定总额。
- 输入日志输出受保护；集合不可变；采用规范整数 JSON 子集与 SHA-256。来源事实仍须服务端 Owner 读取验证，不能信任客户端构造的“已接受/已批准”。
- 具名修订记录旧数据库“强制报价来源”和“准备版本已具备冲突结论”与新流程的差异，未绕过现有数据库守卫。
