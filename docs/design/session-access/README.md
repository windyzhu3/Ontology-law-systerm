## 不变功能边界

本图仅对应业务SPA的`/login`品牌入口。点击后通过既有固定配置进入Keycloak托管认证；用户名和密码不在业务SPA输入或保存。本次没有批准新增注册、短信验证码、二维码登录、记住我、租户自由输入、通知、附件、语音或管理导航，也没有变更OIDC或业务授权合同。

依据[既定设计§4和§7](../../superpowers/specs/2026-09-08-task9-real-user-access-design.md)，此视觉确认不等于Keycloak凭据表单主题、本人任职／合法代办选择页、会话异常／未决恢复状态画面已确认。它也不构成新增品牌配置管理页面的授权。
