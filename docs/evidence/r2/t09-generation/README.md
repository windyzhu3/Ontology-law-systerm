## 实现

ContractCard 继续使用现有工作台壳、MyTasksControl、BusinessNavigation、ledgerMaster.css 和 contractControls.css。未新增产品样式文件；主操作、文字次操作、复选框、历史展开与管理导航保持既有规范。没有将高保真模拟导航复制到产品。

使用既有 PDFBox 填写已审核 PDF 的八个受控字段，保留模板原文。生成阶段保存输入草稿，但不形成合同版本；展示完整提取正文，可下载候选 PDF，人工确认后沿用原材料上传、扫描、接收和 FORM_CONTRACT 命令形成版本。原上传正文路径仍可使用。自动生成模板必须包含完整条款，独立附加条款仍走原上传正文路径。

生成凭据绑定租户、商机、任职、商业来源、参与方、模板、输入与 PDF 摘要，形成版本时重新验证。生成在两次有审计的短事务快照之间执行，PDF 渲染不占用业务事务。缺字段、不支持的字体、文字溢出、不可见或脱离页面的字段均拒绝生成，避免静默丢失费用等正文。
