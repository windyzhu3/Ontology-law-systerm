## 不可妥协的验收基准

- 同一Chat入口，不增加普通用户模块页。
- 同一时刻只有一张完整WorkCard、一个Owner、一个业务目的、一个固定主命令和一个明确结果。
- 选项是主命令参数，不表现为第二主命令。
- Evidence接收不代表业务核验通过；AI不代替Owner决定。
- 退回、重试、补正与后续行动创建新Task，旧Task不重开、不复用。
- 普通用户可见文案不泄漏内部状态码、表名或流程实现。
