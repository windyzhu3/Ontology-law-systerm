- 销售逐项登记：已批准的签署主体、签字/盖章/两者、是否必需、条款依据。至少一项必需要求；缺少依据或重复主体不能继续。
- 核验人增加一项核对：登记的主体、方式及必需项与批准正文完整一致。
- 仅登记有误但批准正文不变，可退回销售补正登记；新安排必须重新核验，旧安排的完成结论不自动沿用。真正改变正文或主体仍返回合同修订。
- 找不到主体不能在签署卡随意新增当事人；回到原合同准备链处理。
