| 组别 | 场景 | 恢复与减负 |
|---|---|---|
| 当前事项与 R1 接续 | 01 商机进展、02 首次联系 | 单张两栏卡片；左侧客户、事实、责任和期限，右侧本次输入与主操作。我的待办按需展开，切换后仍只有一张完整工作卡 |
| 线索导入接续 | 03 导入结果 | 结果表明确哪些已录入、谁接手、下一步是什么；有权销售直接进入该客户的首次联系，再进入同一客户商机 |
| 合同与转案核对 | 04 报价来源合同、05 已授权直接准备、06 转案资料 | 左侧依据、右侧核对；正文预览和人工勾选放在提交之前；材料提示靠近材料清单 |

同一摘要只保留一个编辑位置，取消固定底部重复输入区。“保存草稿”是次要操作，正常记录不要求先点保存候选再点确认。生产接线时，内部仍须完成已有校验、保存、正式命令和回执核对；本设计不改变它们的事务与权限要求。

暖白、石墨色、翡翠绿、6px 圆角、轻边框和弱阴影保持。工作台不套业务管理侧栏或全流程阶段条；管理页不扩展仪表盘。历史资料默认折叠，必要事实直接可见。小屏按依据、输入、确认排列；管理记录点选后定位详情，并可返回原列表。

## 可以实际点击的审阅路径

1. 场景 01：生成摘要建议 → 采用后核对 → 我的待办 → 切换合同。存在修改时，选择继续编辑、放弃修改或保存草稿再切换。采用 AI 建议不会提交。
2. 场景 03：远辰公司导入结果 → 办理首次联系 → 记录有效联系 → 继续同一客户商机跟进。其他记录展示各自负责人和下一事项，不允许越权代办。
3. 场景 04/05：查看报价或直接准备授权 → 预览正文 → 返回后人工勾选 → 提交审批。修改内容后重新预览和核对。审阅工具可模拟结果未知，此时保留当前内容并仅提供结果核对，不允许重复提交或切换事项。
4. 场景 06：查看材料缺项提示 → 人工核对或忽略 → 核对移交材料 → 提交案管审核。结果显示接收人，当前尚未建案。
5. 场景 07：搜索或筛选 → 同页详情 → 办理有权事项。没有匹配记录时，同时清空旧详情；从业务工作卡返回管理入口时保留已有查询条件。
6. 场景 08：安排合格接手人 → 填写说明 → 核对本次交接 → 确认后更新列表。切换记录再返回仍能查看接手人。首次承接起算首次期限，到期事项保留原期限，未来事项不提前办理。
7. 场景 09：登记协调说明和下次核对时间 → 结果为“协调中”；异常仍保留，再次选择该记录可查看协调安排。场景 10 只展示记录，不出现交接主操作。

## 固定业务边界

- 销售链继续承接 R1 的录入、必要去重/补齐、分配与首次联系；不以商机页替代前置业务。
- 保留正式报价与客户接受；直接准备合同必须有对应授权，仍需合同审批与人工签署核验。
- 只有合同明确要求先到账，首款才阻断转案；无此约定时并行跟进。
- 案管审核接收后生成案件，生成后才分类；不在销售合同准备时提前选综法、执行等案管业务类型。
- AI 限于字段提取、跟进摘要、材料缺项提示，全部人工确认。本包交互示范后两项；不扩展原已确认字段提取范围，也不新增聊天、语音或自动业务判定。
- 未保存切换、提交中、未知结果、只读权限及跨角色接续必须保留；交接不等于业务完成，提交审批不等于签署或合同生效。

## 与历史设计及后续实施的关系

本包承接审计报告提出的四组修订，优先纠正 C 场景 18/20/28 的工作台与管理布局、D 场景 44/46 的异常详情与确认负担。A/B/C 的历史批准记录保持，D 仍为 PENDING_REVIEW；E 没有默默覆盖历史批准状态，也不代表 D 全部状态已批准。

E 已确认，按以下顺序调整（实施进展见进度记录）：

1. 共用 App / CurrentCard / workbench.css 与 MyTasks：先统一母版、单一输入位置、主次操作和低高度防遮挡；覆盖 R1 首联与 R2 商机，不只修 R2。
2. LeadIntakeApplication 和业务结果接续：保留客户身份、来源、查询位置及后续办理上下文。
3. 合同准备、预览、人工确认和材料提示：将同一母版映射到既定报价、授权直接准备、签署和转案状态。
4. 管理列表详情与异常处置：按原范围落实授权查询、交接和协调，再与我的待办及后台接续联通。

其余既有场景按该母版逐组映射和检查，不引入新页面类型；若必要状态仍缺少高保真，继续按用户要求先补齐具体画面再确认。R1 PAUSED / R2 NOT_GRANTED 保持。

## 原型边界

本包是本地静态高保真，使用合成客户、人员和固定示例日期；所有状态与草稿只保存在当前页面内存，刷新或用审阅场景切换会重置。没有调用真实 AI、认证、业务 API、数据库或签署服务；合同正文和材料为预览示例，不产生可签署合同文件。十个代表场景不等于整个销售 MVP 已实现或通过业务验收。
